## 🆓 3 STRATEGI GRATIS / MURAH

### Strategi 1: Click-to-WhatsApp Ads (PALING DIREKOMENDASIKAN)
Karena leads Anda dari iklan IG/FB, ganti format iklan jadi **"Click to WhatsApp"**:
- Calon mahasiswa klik iklan → langsung buka WA dengan pesan otomatis "INFO UT"
- Mereka kirim duluan → buka **window GRATIS 72 jam**
- Admin balas sepuasnya tanpa biaya
- ✅ Tidak perlu blast, mereka yang datang — dan GRATIS

### Strategi 2: WhatsApp Business App (100% Gratis)
Aplikasi gratis di Play Store, fitur **Broadcast List**:
- Kirim ke max 256 kontak sekaligus
- ⚠️ Syarat: penerima harus sudah simpan nomor Anda
- Cocok untuk: broadcast ke mahasiswa AKTIF (yang sudah ada di kontak)
- Tidak cocok untuk: 746 leads baru (mereka belum simpan nomor)

### Strategi 3: Cloud API + bayar sekali untuk 746 leads
- Kirim 1 template marketing ke 746 leads ≈ Rp 300–500rb sekali
- Yang balas → masuk window gratis → follow-up gratis
- ROI tinggi: kalau 5% daftar = 37 mahasiswa baru

## 📋 Setup WhatsApp Cloud API — Langkah Detail

### A. Persiapan (sekali saja)
1. **Akun Meta Business** → business.facebook.com → buat akun
2. **Meta for Developers** → developers.facebook.com → "My Apps" → "Create App" → pilih tipe "Business"
3. Tambah produk **"WhatsApp"** → "Set up"
4. Meta kasih **nomor uji gratis** + Phone Number ID + Token

### B. Daftarkan Nomor (PENTING)
- ⚠️ **JANGAN pakai 0822-5063-8289 atau 0852-5283-4986** (nomor admin aktif)
- Pakai **nomor BARU khusus broadcast** (beli SIM baru ~Rp 20rb)
- Alasan: kalau ada masalah, nomor layanan utama tetap aman

### C. Buat Template Message
- Di WhatsApp Manager → "Message Templates" → "Create Template"
- Kategori: **Marketing**
- Submit teks (lihat variasi di bawah) → approval Meta 1–2 jam

### D. Verifikasi Bisnis (untuk volume penuh)
- Upload dokumen usaha (NIB/akta) → Meta verifikasi → dapat centang hijau gratis
